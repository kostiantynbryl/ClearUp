# Product scope

## Positioning

ClearUp by NORVEXA is a transparent Android cleaner for sideload distribution. It avoids misleading RAM boost, CPU cooler and antivirus claims.

## Standard mode

- Storage summary
- MediaStore analysis
- Large files
- Old APK files
- Screenshots
- Temporary files
- Category analyzer
- Installed application list
- System trash
- Exclusions and history in later foundation milestones

## Privileged roadmap

- Shizuku: app cache operations, package actions and richer package metadata
- Root: direct cache/code_cache cleanup, corpse detection, freeze and user uninstall
- Accessibility: fallback only, never required on first launch

## Non-goals

- Advertising
- Subscription paywalls
- Cloud photo analysis
- Aggressive background killing
- Fake performance percentages
- Silent deletion of personal files
